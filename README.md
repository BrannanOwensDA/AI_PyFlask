# AI_PyFlask
AI applications with Python and Flask.

Typical Web App Stack

Frontend -- HTML, CSS, JavaScript
Backend -- Flask == FastAPI
AI model -- Python-based (sklearn, PyTorch, HugingFace, etc.)
Data/Storage -- SQlite, PostgreSQL, Redis, or file system
Hosted via Heroku, AWS, Render, or Docker

| Role               | Like in a Restaurant                             |
| ------------------ | ------------------------------------------------ |
| **JavaScript**     | The waiter — takes orders, delivers dishes       |
| **Flask**          | The chef — takes orders, cooks, and plates meals |
| **HTML/CSS**       | The table setting — what the customer sees       |
| **Database/Model** | The pantry — where the raw info lives            |

## Application Development Lifecycle

Reconnaissance - Why are we building it.

Analysis - Whats most important and viable.

Design - Blueprinting

Code and Test - Build with code, test, and iterate until desired results.

User and System Testing - Does it work as intended?

Production Phase - Full integration

Maintain - Upkeep and Updates
